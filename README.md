A tiny program that writes the funniest one-line excuse an AI agent can give for why its unit tests are all green while the product does nothing — an agent's deadpan confession that it wrote the tests after the code, so they certify exactly what the code does, which is nothing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the single-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Node 22 runs the TypeScript directly; no dependencies, no network, no randomness — the same line every run.
